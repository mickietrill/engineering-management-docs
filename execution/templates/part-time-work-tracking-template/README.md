# Part-Time Work Tracking Template

This document describes a standardized template for tracking work, time allocation, and deliverables of part-time contributors and contractors.

Its purpose is to provide transparency, accountability, and clarity around:

- Worked hours
- Tasks and projects
- Deliverables
- Costs (if applicable)
- Reporting periods

The template is designed to be lightweight, easy to fill, and suitable for weekly or monthly reporting.

## When to Use This Template

This template should be used for:

- Part-time employees
- Contractors and freelancers
- Contributors working limited hours
- External specialists paid by time or scope

Typical use cases:

- Weekly time tracking
- Bi-weekly reporting
- Monthly summaries for payment and planning
- Transparency across multiple projects

---

## Template Structure Overview

The template is organized by daily work entries with automatic period summaries.

### Main Columns

| Column | Description |
|-------|------------|
| Date | Work date |
| Task | Task or activity description |
| Hours per task | Time spent on the specific task |
| Task link | Reference to Jira/GitHub/Notion/etc (optional) |
| Total hours per day | Sum of hours for the day |
| Hourly rate | Rate per hour (if applicable) |
| Total cost | Calculated cost for the day |
| Project | Project or product name |

---

## Period Summaries

The template includes summary rows for defined periods (for example):

- 1–15 of the month  
- 16–end of the month  

Each period summarizes:

- Total worked hours  
- Total cost  

This allows:

- Easy payroll calculations  
- Budget tracking  
- Reporting per contributor  

---

## Recommended Workflow

1. Contributor fills daily rows:
   - Date
   - Task
   - Hours worked
   - Project
   - (Optional) task link

2. Totals are automatically calculated in summary rows

3. Manager reviews:

   - Hours
   - Deliverables
   - Costs

4. Period is approved and archived

## Operational Workflow (Recommended)

This template is typically used as part of a structured part-time collaboration process.

### Contractor Selection

Part-time contributors and contractors should be selected based on:

- Relevant experience and skills
- Portfolio or previous work
- References (when applicable)
- Commercial proposals for teams or agencies

### Agreements and Legal Setup

Work should begin only after a formal agreement is in place covering:

- Scope of work and/or timelines
- Compensation and payment terms
- Confidentiality and IP ownership
- Responsibilities of both parties

(Contract management is typically handled by HR or legal teams.)

### Task Assignment and Control

All tasks should be:

- Defined in written form
- Clearly scoped with:
  - Requirements
  - Acceptance criteria
  - Deadlines

Whenever possible, tasks should be tracked in:

- Jira
- GitHub Issues
- Notion
- Or similar tools

Links can be added in the template for traceability.

### Reporting and Monitoring

Common practice is to collect reports twice per month:

- First half of the month (1–15)
- Second half of the month (16–end)

Each contributor typically has:

- Their own tracking sheet or file
- Clearly separated reporting periods

Reports usually include:

- Tasks completed
- Hours worked
- Total cost (if applicable)

### Review and Approval

At the end of each reporting period:

- Hours and tasks are reviewed by a manager or project owner
- Totals are approved for payroll or invoicing
- Files are archived for future reference

---

## Best Practices

- Fill the template daily (not at the end of the period)
- Keep task descriptions short but clear
- Always associate work with a project
- Use task links when possible for traceability
- Review totals at the end of each period

---

## Notes

- The template is intentionally simple
- It can be extended if needed (additional columns, more periods, etc.)
- Do not overcomplicate unless required by business needs

The main goal is transparency and clarity, not bureaucracy.

---

## Customization

This template can be adapted by:

- Adding more reporting periods
- Adding cost centers or departments
- Splitting by contributor
- Adding approval status column

Keep changes minimal to preserve simplicity.
